🛡️ Admin Review Rule

A report does not automatically mean the reported member has done something wrong. Admin must review the report before taking account action.

  • Reports do not automatically suspend accounts.
  • Multiple reports do not automatically create punishment.
  • Blocking a contact does not create an admin report.
  • If no violation is found, close the report without account punishment.
  • Warning, suspension or removal should only be used after admin review.
